# Student Portfolio Website

A clean, responsive personal portfolio website for an MCA student.

## Features
- Responsive design for desktop, tablet and mobile
- Hero section with call-to-action buttons
- About Me section
- Skills with progress bars
- Project showcase
- Education timeline
- Contact section
- No frameworks or build tools required

## Technologies
- HTML5
- CSS3

## Run Locally
1. Clone this repository.
2. Open `index.html` in a browser.

## Customize
Replace the placeholder email in `index.html` and update the project, education and skills information with your own details.
